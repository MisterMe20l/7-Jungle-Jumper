Thomas Wellmann da Riva Cesar's Spielprojekt: 'Jungle-Jumper'

2D, almost open world game with jungle exploration theme and a boss fight on a cave. Still only one level though.
Main (unknown) Keys:
-'F'/'West Button' to hold up to the wall;
-'Mouse 1'/'Right Trigger' to shoot;
-'E'/'North Button' to Interact;
-'ESC'/'Touch Pad' to pause;

All damage instances deal 10 of it. The player has 100 HP and the boss 500.
Music theme with forest and cave white-noise + soundeffects.
Kill the boss to unlock the exit portal and return to the main menu.
